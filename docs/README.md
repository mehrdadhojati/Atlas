# Atlas — Map of Content

This vault is the single source of truth for the engineering documentation of
**Atlas**, a VS Code extension that renders an Obsidian-style, force-directed
graph of the Markdown notes in the current workspace.

## Where to start

- [[System Architecture]] — high-level design, components, and data flow.
- [[Software Architecture]] — layers, patterns, and principles.
- [[Functional Specification (FSD)]] — functional requirements by feature.
- [[Non-Functional Requirements (NFR)]] — quality attributes.

## Folders

- `Software Engineering/System Architecture/` — system-level design.
- `Software Engineering/Software Architecture/` — software design and patterns.
- `Software Engineering/Specifications/` — FSD and NFR.
- `Software Engineering/decisions/` — ADR and TDR records.
- `features/` — one file per user-facing feature.
- `sessions/` — discussion records.
- `templates/` — document templates.
