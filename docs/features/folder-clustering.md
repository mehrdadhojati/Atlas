# Folder Clustering

Groups notes by their top-level folder so unlinked files gather together instead
of scattering. A soft cluster force pulls each node toward its folder's centroid
without clamping positions, so dragging stays unrestricted. Each folder is tinted
a distinct color, and a translucent convex-hull blob is drawn behind it to make
membership obvious.
