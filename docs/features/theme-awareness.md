# Theme Awareness

All colors come from VS Code theme CSS variables (`--vscode-editor-background`,
`--vscode-charts-blue`, `--vscode-charts-purple`, etc.), so the graph adapts
automatically to light/dark/any theme. No colors are hardcoded.
